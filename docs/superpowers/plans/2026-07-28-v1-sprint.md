- docs 与示例 README 用**中文**撰写，风格对齐 `docs/01-introduction.md`（`## 2.1` 式编号小节）。
- 文档中的代码示例必须取自或最小改自 `_examples` 下可编译代码，**不新造未验证的代码**。
- **零功能代码变更**：只允许改注释、文档、README、配置文件；不改任何导出 API 签名。
- **CLI 命名不动**：`*CLI` 类型、`lynx.New`、`Lynx.CLI()` 全部保留，仅清理误导性注释。
- **不打 v1.0.0 tag**；RELEASE.md 只写流程。
- Commit message 用英文 conventional commits（本计划一律 `docs:` 前缀）；直接在 master 分支提交；**不 push**（push 由主会话在用户确认后执行）。
- `go.work` / `go.work.sum` 已被 gitignore，不得 `git add`。
- 四个 docs 文件名必须是 `02-quick-start.md`、`03-core-concepts.md`、`04-component-system.md`、`05-servers.md`（`docs/01-introduction.md` 末尾已按此链接）。
